The `!8ball` command simulates a magic 8-ball toy: ask it a question and it answers with a random verdict. The chatbot displays only the answer itself, without any introductory phrase such as "The 8-ball says...".

## Usage

To use the command, type `!8ball` followed by an optional question in the chat. The chatbot will respond directly with a random fortune-like answer, without any introductory text.

```streamelements
!8ball [question]
```

The `[question]` part is entirely optional and does not influence the random outcome.

## Configuration

Enable the 8ball module under `Chatbot` -> `Modules`, where you can also customize the list of possible responses the command draws from.

For a clean response, configure the command to display only the randomly selected answer, without adding "The 8-ball says..." or any other introductory text.
